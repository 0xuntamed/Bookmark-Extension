# Bookmark Notes

A Chrome Manifest V3 extension for keeping personal notes beside each bookmark.

## Load it in Chrome

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Choose Load unpacked.
4. Select this folder: `C:\Users\THALHA AHMED\Documents\Bookmark Extension`.

## Use it

- Click the extension button to search bookmarks and open a bookmark's notes page.
- Use Notes for the current tab to create a bookmark if the page is not bookmarked yet.
- Highlight text on a page, right-click, then choose Save selection to bookmark notes.
- Paste text manually into Saved text on a bookmark notes page.

Notes are saved in `chrome.storage.local`, keyed by Chrome bookmark ID.
